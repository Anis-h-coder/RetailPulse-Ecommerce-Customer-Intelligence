# Dataset

This project uses the **Online Retail** transactional dataset for e-commerce sales and customer intelligence analysis.

The dataset contains retail transaction records including:

- Invoice information
- Product details
- Quantity
- Unit price
- Customer information
- Country
- Transaction date and time

## Data Preparation

The dataset was cleaned and prepared using Python before analysis. The preprocessing included:

- Removing duplicate records
- Handling missing product descriptions
- Removing cancelled transactions
- Filtering invalid quantities and prices
- Creating revenue and date-related features

The prepared data was then used for:

- Exploratory Data Analysis
- RFM Customer Segmentation
- Repurchase Prediction
- Revenue-at-Risk Analysis
- Power BI Dashboard Development

## Data Availability

The raw dataset is **not included in this repository**.

The notebooks contain the data preparation and analysis workflow used for the project.
